# 프런트엔드 개발 도구로 Vite, React, TypeScript, Bun 사용

- 상태: 채택
- 작성일: 2026-09-06

## 배경

게임의 웹 화면을 개발하기 위한 기본 기술 구성과 설치·실행 방식을 정한다.

## 결정과 이유

사용자가 지정한 React + TypeScript 템플릿과 Bun 기반 설치 방식을 프로젝트의 기본 구성으로 채택한다.

- **Vite**: 개발 서버와 프로덕션 빌드에 사용한다.
- **React**: 게임 화면의 UI를 구성한다.
- **TypeScript**: 애플리케이션 코드 작성과 정적 타입 검사에 사용한다.
- **Bun**: 의존성 설치와 프로젝트 스크립트 실행에 사용한다.

초기 프로젝트는 `bun create vite`의 `react-ts` 템플릿으로 생성했다.

## 검토한 대안

별도의 대안 비교는 진행하지 않았으며, 지정된 기술 구성으로 시작한다.

## 결과 및 트레이드오프

- 개발 환경에 Bun이 필요하다.
- `bun install`로 의존성을 설치하고 `bun run dev`로 개발 서버를 실행한다.
- `bun run build`로 TypeScript 타입 검사와 Vite 빌드를 수행한다.
- 의존성 버전은 `package.json`과 `bun.lock`으로 관리한다.
- 이 결정은 프런트엔드 개발 구성에 한정하며, 백엔드 기술 선택은 포함하지 않는다.
