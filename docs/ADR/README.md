# 기술 결정 기록 (ADR)

기술 선택과 그 배경, 검토한 대안, 결정에 따른 영향을 기록합니다.

## 파일명 규칙

`YYYY-MM-DD-NNN-주제.md`

- 날짜는 문서 작성일을 사용합니다.
- 번호는 `001`부터 시작하며, 날짜가 바뀌어도 폴더 전체에서 누적합니다.
- 주제는 소문자 영문 kebab-case로 작성합니다.
- 예: `2026-09-06-001-state-management.md`

## 문서 내용

- 상태: 제안, 채택, 폐기, 대체
- 배경과 해결할 문제
- 검토한 대안
- 결정과 이유
- 결과 및 트레이드오프
