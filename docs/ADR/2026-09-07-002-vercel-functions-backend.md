# 백엔드 실행 환경으로 Vercel Functions 사용

- 상태: 채택
- 작성일: 2026-09-07

## 배경

방 생성과 입장, 좌석 선택, 게임 진행 요청을 처리할 백엔드가 필요하다. 초기에는 별도 서버 운영 부담을 줄이고 무료 사용 범위 안에서 필요한 기능을 구현하는 것을 목표로 한다.

## 검토한 대안

- Hono 등을 사용한 별도 백엔드 애플리케이션
- Firebase의 Hosting, 데이터베이스, Functions를 활용한 통합 구성
- AWS Lightsail에서 직접 서버 운영

Hono는 프레임워크이고 Vercel Functions는 실행 환경이므로 서로 배타적인 선택은 아니다. 현재는 별도 백엔드 프레임워크 도입을 결정하지 않는다.

## 결정과 이유

- 초기 백엔드는 Vercel Functions를 사용한다.
- 방 생성·입장 등 서버 처리가 필요한 기능을 HTTP API로 구현한다.
- 무료 사용 범위에서 문제를 해결하고, 별도 서버를 구축·운영하는 부담을 줄이기 위해 선택한다.
- 무료 사용 범위 내 운영은 목표이며, 모든 사용량과 외부 서비스 비용이 무료임을 보장하는 결정은 아니다.

## 결과 및 트레이드오프

- 백엔드 도입만을 이유로 저장소를 분리하거나 모노레포로 전환하지 않아도 된다.
- 방과 게임 상태는 함수 메모리에만 의존하지 않고 외부 저장소에 보관해야 한다. 데이터베이스 선택은 별도로 결정한다.
- 함수 실행 시간과 사용량 한도를 고려해야 한다. 실시간 상태 공유 방식은 이번 결정에 포함하지 않는다.
- 향후 기능, 사용량, 비용 또는 운영 요구가 달라지면 다른 백엔드 프레임워크나 실행 환경으로 변경할 수 있다.
- 무료 사용 범위를 넘어가거나 현재 실행 환경이 요구사항을 충족하지 못하면 유료 유지와 다른 기술로의 이전을 비교하여 후속 ADR로 기록한다.
