# 사이트맵

현재 구현된 화면과 기획 중인 화면을 함께 정리한다. 방 내부 항목은 사용자 흐름이며, 각각 별도 페이지로 나눌지는 미정이다.

```text
시작 화면 (/)
├─ 방 만들기 → 방 화면 (/rooms/:roomId)
│  ├─ 입장용 QR 표시
│  ├─ 입장 정보 입력
│  ├─ 좌석 선택·확정
│  └─ 게임 진행
│     ├─ 최초 오야 선정
│     ├─ 질문·명식 추리·밝혀진 명식 공유
│     └─ 화료·다음 국 진행
├─ 사전 / 위키 [구상]
└─ 설문 [구상]
```

| 항목 | 상태 | 내용 |
| --- | --- | --- |
| 시작 화면 | 구현됨 | 4~6명 인원 선택, 모의 응답으로 방 생성 |
| 방 화면·QR | 구현됨 | 방 입장 URL을 담은 QR 표시 |
| 입장 정보·좌석 | 기획됨 | 출생 정보 입력, 좌석 선택과 전원 확정 |
| 게임 진행 | 기획 중 | 오야 선정, 질문과 추리, 화료 및 국 전환 |
| 사전 / 위키 | 구상 | 게임 규칙과 용어를 찾아보는 공간. 명칭과 범위 미정 |
| 설문 | 구상 | 참여 대상, 목적, 문항 및 노출 시점 미정 |

입장 정보 입력 이후의 URL과 사전·위키, 설문의 URL은 미정이다. 회원가입·로그인 화면 없이 참여하는 방향이다.
