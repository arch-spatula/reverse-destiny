# 방 만들기

## 범위

- 게임을 진행할 방을 만든다.
- QR 생성은 방 만들기 기능에 포함한다.
- QR을 통한 방 입장, 개인 정보 입력, 좌석 선택 및 확정을 다룬다.

## 사용자 흐름

1. 사용자가 방 생성을 요청한다.
2. 생성된 방의 QR을 각자 휴대폰으로 스캔하여 입장한다.
3. 생년월일, 태어난 시간, 태어난 도시, 성별을 입력한다. 태어난 시간은 `모름`을 선택할 수 있다.
4. 입력을 마치면 좌석 선택 화면으로 이동한다.
5. 다른 플레이어의 좌석 선택 상태를 확인하고, 현실의 자리와 일치하는 빈 좌석을 선택해 확정한다.
6. 모든 플레이어가 좌석을 확정하면 좌석이 고정된다.

## 요구사항

### 방 생성 및 QR 입장

- 방은 사용자의 생성 요청이 있을 때 생성한다.
- 생성한 방에 대응하는 QR 코드를 생성할 수 있어야 한다.
- 각 플레이어는 자신의 휴대폰으로 QR을 스캔하여 해당 방에 입장한다.
- QR 생성에 사용할 라이브러리 등 기술 선택은 별도 ADR에서 다룬다.

### 입장 정보

- 입장 시 각 플레이어의 생년월일, 태어난 시간, 태어난 도시, 성별을 입력받는다.
- 태어난 시간에는 `모름` 토글을 제공한다. `모름`을 선택하면 시간 입력 없이 진행할 수 있다.
- 태어난 시간 입력 또는 `모름` 선택을 포함한 입장 정보 입력을 마치면 좌석 선택 화면을 표시한다.
- 태어난 시간의 `모름` 여부는 이후 다음 국으로 넘어갈 때 `skip 권장` 표시에 참고한다. 구체적인 표시 기준은 별도로 정한다.

### 좌석 선택과 확정

- 다른 플레이어가 선택한 좌석을 볼 수 있다.
- 비어 있는 좌석을 선택한 뒤 확정한다. 하나의 좌석을 여러 플레이어가 동시에 차지할 수 없다.
- 현재 선택한 좌석을 다시 누르면 선택을 해제할 수 있다.
- 좌석 확정을 취소할 수 있다.
- 모든 플레이어가 확정하면 좌석이 고정된다.
- 현실의 좌석 배치 및 오야 순서는 [게임 룰](game-rules.md)을 따른다.

### 정보 공개 범위

- 플레이어의 위치는 서로 공유하지 않는다.
- 좌석 선택 및 확정 상태, 오야의 밝혀진 명식, 현재 선택한 질문 등 게임 진행에 필요한 정보와 기물은 공유한다.
- 각 플레이어의 명식은 서로 비밀로 유지한다. 오야의 명식도 게임 진행 중 밝혀진 부분만 공유한다.

## 수용 기준

- 생성한 방에 대한 QR 코드를 생성할 수 있다.
- 각자 휴대폰으로 QR을 스캔하면 해당 방의 입장 흐름으로 연결된다.
- 입장 정보를 입력하고 좌석 선택 화면으로 이동할 수 있으며, 태어난 시간을 몰라도 `모름`을 선택하여 진행할 수 있다.
- 다른 플레이어가 선택한 좌석을 확인하고 빈 좌석을 선택·확정할 수 있다.
- 선택한 좌석을 다시 눌러 해제하거나 좌석 확정을 취소할 수 있다.
- 모든 플레이어가 좌석을 확정하면 좌석이 고정된다.
- 다른 플레이어에게 위치와 비공개 명식이 노출되지 않으며, 게임 진행에 필요한 공개 정보는 공유된다.

## 미결정 사항

- QR에 담을 정보: 방 입장 URL 또는 방 식별 정보 등
- QR 생성 시점: 방 생성 시 자동 생성 또는 사용자 요청 시 생성
- QR 표시 위치 및 공유·다운로드 지원 여부
- 방 종료 시 QR의 유효성 및 만료 정책
- 전체 좌석 고정 이후에도 확정을 취소할 수 있는지 여부
- 확정한 좌석을 다시 누를 때의 선택 해제 및 확정 취소 처리 방식
- 모든 플레이어의 확정 여부를 판단하기 위한 참여 인원 확정 시점
- 태어난 시간 `모름` 여부에 따른 다음 국의 `skip 권장` 표시 기준
- 입장 시 입력한 원본 정보(생년월일, 태어난 시간, 태어난 도시, 성별)의 공개 범위
